# 买不买｜开发与验收报告

课程交付包括 Uni-app 源码、H5 与微信小程序构建产物、uniCloud 配置以及 4 页 A4 立项说明。可通过本地演示完成发起匿名申请、旁观者投票与评论、作者复盘、账本联动和小组打卡。共享数据模式需要部署到可用的阿里云 uniCloud 服务空间。 [运行说明](../README.md) · [立项说明 PDF](./买不买-项目立项与原型说明.pdf) · [云端配置](../uniCloud-aliyun/README.md)

## 智能体逐项报告

17 位协作智能体按实际任务列出，主控另列。表中链接指向对应代码、素材、文档或测试入口。

| 智能体 | 实际工作与验收证据 |
| --- | --- |
| `root`（主控） | 搭建并整合 Uni-app 工程、导航、共享组件与各业务模块，统一字体、图标和动效。补充云端断网重试测试，核验双端产物并打包课程交付。 [工程命令](../package.json) · [应用框架](../src/components/AppShell.vue) · [全局样式](../src/styles/base.css) · [云端适配](../src/lib/remote.js) · [断网恢复测试](../tests/remote.test.mjs) |
| `art` | 制作裁判大厅的珊瑚红裁判槌主视觉，以 WebP 提供桌面和移动端共用的图片资产。成品已纳入 H5 大厅和立项 PDF。 [主视觉](../src/static/products/hero.webp) |
| `art/thumbs` | 为机械键盘、通勤包、拍立得、耳机、球鞋和台灯制作六张统一风格的 WebP 缩略图。素材由示例申请在大厅与详情调用。 [商品素材](../src/static/products/) · [示例数据](../src/lib/seed.js) |
| `assignment` | 撰写立项、目标用户、业务规则、技术与内测计划，对齐实际界面文案，制作含桌面与移动端原型截图的 A4 PDF。逐页渲染核对中文字体、页码与裁切，并整理本报告。 [可编辑源稿](./项目立项与原型说明.md) · [提交版 PDF](./买不买-项目立项与原型说明.pdf) |
| `assignment/proof` | 对照 Vue 页面和规则校对立项稿，确认发起消费申请、我的档案与复盘按钮文案，核对私密小组可见范围、周榜口径及免费加急演示。 [立项说明](./项目立项与原型说明.md) |
| `case` | 完成申请详情、预算与备选方案展示、投票、评论、举报、作者复盘和加急。桌面浏览器流程覆盖分享地址、匿名劝言、举报和复盘联动。 [详情页](../src/components/CaseDetail.vue) · [详情操作](../src/lib/case-actions.js) · [浏览器验收](../tests/browser.spec.mjs) |

| `cloud` | 提供云函数、五类集合配置和部署说明。服务端管理匿名令牌、计票与复盘权限、图片上传、私密账本、每日打卡和举报。加入写入后的刷新恢复及同一请求编号去重。 [云函数](../uniCloud-aliyun/cloudfunctions/buy-or-not/) · [数据库配置](../uniCloud-aliyun/database/) · [双端验收流程](../uniCloud-aliyun/README.md#双端验收) |

| `community` | 完成攒钱自律小组的发现和个人列表、公开小组加入、私密组创建与每日打卡。主控补上公开组当日匿名打卡人数。浏览器验收覆盖公开组加入、人数更新、刷新保留及私密组的发现列表可见性。 [小组页](../src/components/CourtGroups.vue) · [浏览器验收](../tests/browser.spec.mjs) |
| `community/ranking` | 完成最有争议、驳回最多、热评最多三类周榜，按本周发布的申请计算，可从榜单进入详情。浏览器验收覆盖榜单切换和跳转。 [榜单页](../src/components/CourtRanking.vue) |
| `domain` | 实现响应式本地业务数据、持久化、作者权限、单次有效投票、账本同步、举报去重与每日打卡。5 项 Node 测试覆盖改票、复盘、重复打卡、校验与写入失败恢复、金额格式。 [业务逻辑](../src/lib/store.js) · [规则测试](../tests/domain.test.mjs) |
| `domain/samples` | 编写示例申请、匿名评论、攒钱小组及消费历史，让课堂演示能覆盖不同分类、投票结果及复盘状态。 [示例数据](../src/lib/seed.js) |
| `feed` | 完成裁判大厅、推荐排序与加急优先、分类筛选、社区概况及热门申请。桌面采用双列，移动端调整内容顺序。浏览器验收覆盖分类、空态、排序和移动布局。 [大厅](../src/components/CourtFeed.vue) |
| `feed/casecard` | 完成申请卡、商品图、金额、票数比例、投票按钮和进入详情的交互。浏览器验收验证改票无重复计数，以及键盘打开详情和投票。 [申请卡](../src/components/CaseCard.vue) |
| `profile` | 完成个人申请筛选、投票历史、忍住比例、估算省下、账本支出和手动记账，加入会员权益说明。浏览器验收覆盖复盘入账与撤销、手动记账及刷新保留。 [个人档案](../src/components/CourtProfile.vue) |
| `qa` | 在 H5 发布版上执行 14 项 Chrome 浏览器验收并拦截所有外网流量，覆盖主要操作、键盘和 320／390 像素移动布局。另在 Firefox 与 WebKit 执行移动首屏、投票和刷新测试。 [Chrome 验收脚本](../tests/browser.spec.mjs) |
| `qa/wechat_preflight` | 使用微信开发者工具自带编译器检查 12 份 WXML 和 10 份 WXSS，核对其他构建文件。使用模拟 `wx` 接口验证 3 个页面和 9 个组件能注册。 [页面注册](../src/pages.json) · [微信项目配置](../src/manifest.json) |

运行 `npm test` 可复查上述 10 项自动化测试。

提交包包含源码、双端构建产物、测试、云部署配置、立项说明 PDF 和本报告。从解压包使用 Python 本地静态服务器运行 H5，屏蔽外网后复跑 14 项浏览器验收通过。解压后小程序构建产物也通过微信原生编译检查。 [离线运行说明](../README.md#运行演示)

加急可在演示中使用并提高大厅推荐顺序。会员权益和广告合作为商业设想，演示无需付费。原型私密小组仅创建者可见。云端举报工单和下架在 uniCloud 控制台处理。 [课程方案](./项目立项与原型说明.md) · [审核流程](../uniCloud-aliyun/README.md#双端验收)
